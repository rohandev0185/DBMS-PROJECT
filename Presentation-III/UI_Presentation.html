Frontend Design & User Experience Slide 3 of 5
Backend Tech Stack

Server Architecture & Database Connectivity

Robust Python Flask REST microservices backed by MySQL relational database
Web Framework

Python 3.12 & Flask

  • Lightweight WSGI framework serving RESTful JSON endpoints.
  • Configurable environment via config.py for local MySQL instance credentials.
  • Centralized error handling returning JSON error payloads with proper HTTP status codes.
Database Driver

PyMySQL Connector

  • Pure-Python MySQL client driver providing direct TCP socket connection.
  • Parameterized Queries (%s) across all endpoints to prevent SQL injection vulnerabilities.
  • Automatic transaction management with explicit conn.commit() and conn.rollback().
RDBMS

MySQL 9.7 Server

  • Normalized relational schema (LibraryDbms) maintaining 3NF integrity.
  • Foreign Key constraints with ON DELETE CASCADE / RESTRICT.
  • Complex JOIN queries, aggregations, and fine calculation views executed natively.

CRUD Operations & REST API Endpoints

Direct mapping of UI interactions to SQL database mutations
Operation: INSERT

Record Creation

  • Endpoint: POST /api/books
  • UI Action: "Add New Book" Modal with ISBN, Title, Category, Author, Publisher.
  • SQL Execution: INSERT INTO BOOK (...) VALUES (...)
  • Result: Real-time table refresh + toast notification.
Operation: DELETE

Record Removal

  • Endpoint: DELETE /api/books/<id>
  • UI Action: Delete button on catalog rows with confirmation prompt.
  • SQL Execution: DELETE FROM BOOK WHERE BookID = %s
  • Result: Row smoothly unmounts; constraints verified.
Operation: VIEW

Live Query & Read

  • Endpoints: GET /api/books, GET /api/issues
  • UI Action: Live catalog table, member loan ledger, metrics cards.
  • SQL Execution: Multi-table LEFT JOIN queries for live availability status.
  • Result: Instant search, sort, and status badges.
